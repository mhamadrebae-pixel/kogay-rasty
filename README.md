# سیستمی ئۆنلاینی تەواو بێبەرامبەر ($0 دۆلار) — ٢٤/٧ ئۆنلاین
# Kogay Rasty 100% Free Cloud System (Google Firebase + ImgBB)

ئەم سیستمە تەواو سەربەخۆیە لە فۆڵدەری `online-system/`، دروستکراوە بۆ ئەوەی خاوەن کۆگا بتوانێت لە هەر شوێنێک بێت بە مۆبایلەکەی وێنە بگرێت و کاڵا زیاد بکات، بەبێ پێویستی بە کۆمپیوتەری کراوە و بەبێ یەک دینار مەسرەف ($0).

---

## ١. چۆن ئێستا تاقی بکەیتەوە؟

1. لەسەر مۆبایل یان کۆمپیوتەرەکەت، فایلی **`online-system/admin.html`** بکەرەوە.
2. تێپەڕەوشەی چوونەژوورەوە بنووسە:
   ```
   1234
   ```
   (دەتوانیت لەناو `config.js` ئەم تێپەڕەوشەیە بگۆڕیت بۆ هەر ژمارەیەک کە دەتەوێت).
3. دەست لە بەشی وێنە بدە ➜ کامێرا دەکاتەوە ➜ وێنەیەک بگرە و ناوی کاڵاکە بنووسە ➜ کلیک لە «زیادکردن بۆ فرۆشگا» بکە!
4. بۆ بینینی فرۆشگاکە، فایلی **`online-system/store.html`** بکەرەوە، دەبینیت کاڵاکەت بە چرکەیەک دەرکەوتووە و کڕیار دەتوانێت داواکاری بە واتسئەپ بنێرێت.

---

## ٢. چۆن کلیلی فەرمی بێبەرامبەری گووگڵ (Google Firebase) دابنێیت؟ (تەنها ٢ خولەک)

سیستمەکە ئێستا بە خۆماڵی لەناو وێبگەڕدا کار دەکات، بەڵام بۆ ئەوەی ببێتە فەرمی ٢٤/٧ ئۆنلاین لەسەر سێرڤەری گووگڵ بەبێ پارە:
1. بچۆ سەر: **https://console.firebase.google.com** (بە جیمەیڵی خۆت یان هی موشتەرییەکەت).
2. کلیک لە **Add Project** بکە و ناوێکی لێ بنێ (بۆ نموونە: `kogay-rasty`).
3. لە بەشی چەپ بچۆ سەر: **Build ➜ Realtime Database ➜ Create Database** (هەڵبژاردنی Test Mode).
4. لە بەشی ڕێکخستنی پرۆژەکە (Project Settings)، بەشی **Web App (</>)** هەڵبژێرە، کۆدی `firebaseConfig` کۆپی بکە و لەناو فایلی **`config.js`** دایبنێ!

---

## ٣. چۆن کلیلی بێبەرامبەری وێنە (ImgBB) دابنێیت؟ (تەنها ٣٠ چرکە)

1. بچۆ سەر: **https://api.imgbb.com**
2. کلیک لە **Get API Key** بکە.
3. کۆپیکردنی کلیلەکە و دانانی لەناو فایلی **`config.js`** لە بەشی `imgbbApiKey`.

پیرۆزە! ئێستا کۆگاکەت خاوەنی سیستمێکی مۆدێرن و ٢٤ کاتژمێرییە بەبێ یەک فلس مەسرەف.
